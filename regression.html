Regression

Multivariate regression

Reminder
  1. If using categorical predictors (for example, testing 2 x 2 factorial designs using regression), make sure that the IVs are effect coded, so that one level is -1 and the other is +1. This allows you to compare each group to the overall average of the sample, rather than to the reference category. It also makes interpretation of interactions easier. See Recoding variables for a guide.
  2. If testing moderation by a continuous variable, make sure all continuous variables involved in interactions have been mean centred. This reduces multicollinearity between the interaction and its constituent variables, and again, makes interpretation of interactions easier. See Mean centring and standardising for a guide.

I like to conduct multivariate regression analyses using the following code, using the base r functions + the apaTables package [@apaTables2026] to produce publication-ready tables.

In this example, we are testing a 2 x 2 factorial design, with one continuous moderator. The factors have been effect-coded (-1 and +1), and the continuous moderator has been mean-centred.

We must build three models representing each ‘block’ in hierarchical regression. The main effects are entered in Block 1, the two-way interactions are entered in Block 2, and the three-way interaction is entered in Block 3.

Understanding the regression formula

When specifying regression models in R, we use formula syntax that describes the relationship between variables.

The general formula is: the dependent variable is to the left of the ~ symbol and the predictor variables are to the right of this symbol. The ~ symbol can therefore be understood as “is predicted by” or “is explained by.”

Therefore the formula DV ~ IV1 + IV2 can be read in plain English as “DV is predicted by IV1 and IV2.”

Additional predictors are separated by a + symbol. If you are examining the interaction between variables, you use the colon symbol :.

For example, the formula DV ~ IV1:IV2 tests whether the effect of IV1 on DV depends on the level of IV2. Main effects and interactions must be added separately.

The asterisk symbol * is shorthand that automatically includes all main effects and interactions between variables. So, if you wanted to test a three-way interaction, the code IV1 * IV2 * IV3 would automatically include the main effects of IV1, IV2, and IV3, all two-way interactions, and the three-way interaction. This expands to:

DV ~ IV1 +
     IV2 +
     IV3 +
     IV1:IV2 +
     IV1:IV3 +
     IV2:IV3 +
     IV1:IV2:IV3

If you are testing a hierarchical regression model where you need to enter the main effects and two-way interactions at a separate step from the three-way interaction, you will need to build separate models to do this. An example of this is provided below.

Finally, I() forces R to evaluate an arithmetic expression literally and use the result as a single predictor, rather than interpreting it as formula syntax. I(IV1 * IV2) creates one new numeric column equal to IV1 × IV2 – that is, mathematically identical to the IV1:IV2 interaction term, but stored and labelled as an ordinary product variable rather than a formula-level interaction.

  • This is necessary for calculating the standardised betas in apa.reg.table(). To be clear, I(IV1 * IV2) will give the exact same coefficients (B), SEs, and p-values as IV1:IV2 and IV1*IV2. The difference only matters once you pass the model to apa.reg.table(), because apa.reg.table() calculates the standardised beta for each predictor by re-fitting the model on standardised variables. To do this, it needs each interaction term to already exist in the data as an actual numeric column with a name it can parse (e.g. I(IV1 * IV2)). If you don’t include the interaction terms in I(), the table will still be produced, but you won’t get standardised betas or 95% confidence intervals for standardised betas.

Block 1: Main effects

library(apaTables)

# Block 1: Main effects
model_b1 <- lm(DV ~ IV1 + IV2 + moderator_mc, dat)
summary(model_b1)

What this is doing:

  • This model estimates the direct effects of each predictor on the dependent variable.

  • DV is the dependent/outcome/criterion variable. IV1 and IV2 are effect-coded categorical predictors (where -1 = one level, +1 = the other level). moderator_mc is a continuous moderator that has been mean-centred.

  • All predictors are separated by +, meaning they are tested on average across all levels of the other variables (i.e., they are main effects).

  • As we can see from the output, the model is significant, F(3, 296) = 57.07, p < .001 and explains 37% of the total variance in the DV. All main effects are significant.

Block 2: Two-way interactions

model_b2 <- lm(DV ~ IV1 + IV2 + moderator_mc + 
                 I(IV1 * IV2) + 
                 I(IV1 * moderator_mc) + 
                 I(IV2 * moderator_mc), 
               dat)
summary(model_b2)

What this is doing:

  • The apa.reg.table() function from apaTables package [@apaTables2026] combines the results from all three regression models into a single, publication-ready table. This means you do not have to worry about small errors and inconsistencies when copying over values – whoopee!

  • The table includes regression coefficients (B), standard errors, standardised coefficients (β), 95% confidence intervals, model R² values, changes in R² across blocks, and significance tests for individual predictors.

  • As we can see from the delta R² values, each model was a significant improvement on the one before.
